# Mobile interface refresh

Update Flutter's screens to a coherent, lighter visual system informed by Impeccable and Mobile Design. Preserve the app's Vietnamese copy where it identifies an action, the four tabs, and the existing data contracts and workflows.

## Plan and checklist

- [x] Review current workspaces, the UI skills, app capabilities and the representative screens.
- [x] Define shared typography, colors, navigation and surface treatment.
- [x] Apply the system across sign-in, trips and planning, map, expenses, and account/profile.
- [x] Validate mobile layout, text scaling, keyboard reach, sign-in flow, map controls and current planning options using Flutter tests and rendered screen captures.

The 88 Flutter tests cover the 320- and 390-pixel layouts, 200% text size, keyboard reach, sign-in, the planner, foreground GPS and route playback. Six JavaScript tests cover the bridge between the map and live location. Visual review used Flutter widget captures with fixture data.

# Try a group trip

Apply the Alembic migrations before starting FastAPI. Use the established
Flutter run command with the base URL for that API.

1. Sign in with two test accounts in separate browser profiles or devices. Open
   **Chuyến đi nhóm** as leader, create a trip, set the total headcount and
   budget, and create an invitation.
2. Join using the code on the second device. Each person contributes a place.
   The leader can add a guest and contribute on their behalf.
3. Generate alternatives. Check that both accounts can view and vote. Confirm
   as leader. Read the chat notice and open the route as a member.
4. Add a shared expense for two selected people and record a repayment.
   Compare the shared total and balances before and after repayment.
5. As leader, open **Đổi kế hoạch**, mark a stop visited, and choose a new
   starting place. The confirmed route remains visible until the leader
   accepts another one.
